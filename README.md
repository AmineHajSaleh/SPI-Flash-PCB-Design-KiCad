# SPI Flash Memory PCB — KiCad

## Project Overview

Design of a 2-layer PCB for a W25Q32JV SPI Flash memory, intended to interface with an external STM32 microcontroller.

This personal project was developed to strengthen my practical skills in electronic schematic design, PCB layout and routing using KiCad.

## Technical Features

- SPI interface: SCK, MOSI, MISO, CS
- 3.3 V power supply
- 100 nF decoupling capacitor
- 10 kΩ chip-select pull-up resistor
- 2-layer PCB design
- Ground plane on B.Cu
- Ground vias and component placement optimization

## Design Workflow

1. Electronic schematic design
2. Component footprint assignment
3. Electrical Rules Check (ERC)
4. PCB component placement
5. Signal and power routing
6. Ground plane implementation
7. Design Rules Check (DRC)
8. 3D PCB visualization

## Validation Status

- Schematic and PCB designed in KiCad
- Design rules checked
- 3D visualization completed
- **Physical PCB manufacturing and hardware testing not performed**
